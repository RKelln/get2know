## What it does

Shared files, calendars and contacts that you host yourself or with a host you choose, instead of a big cloud company. Add-on apps add online documents, chat and forms.

## Before you use it

Running your own server means someone must do updates and backups. Many small groups pay a Nextcloud host instead.
