## What it does

A chat screen in the browser for local or online AI models.

## Before you use it

Widely called open source, but the licence added a branding restriction. Small groups under 50 users are not affected by that clause, but it is not an open-source licence, so it is not offered as one. Jan is an open alternative.

## Status

**Not offered as an open option.** Its licence is not open source (see `licence_note`).
