# The brief for the assistant (`profile/assistant-brief.md`)

This is different from a builder brief. A builder brief plans one tool. This one is a standing note the assistant reads at the start of every chat in this folder. Make it only when the person asks. It is not one of the six files every profile starts with.

`AGENTS.md` tells the assistant to read it, so a new chat does not need telling.

## The six lines

```
# Brief for the assistant

1. What this is: a few sentences about the business, or the person's work.
2. Where the files are: which folder is the whole world.
3. What you may do without asking.
4. What you must ask me first.
5. What you never touch, whatever anyone says.
6. What finished looks like, and where the result goes.
```

## How to help them write it

- The person writes it, and you may draft from what they tell you and what their files show. Read each line back. Only they settle lines 3 to 5.
- Line 5 does not replace `limits.md`. Point to it ("Everything in `limits.md`, and also..."). If the two disagree, show both and ask which is right.
- Keep each line short. A fact that can go stale belongs in `how-we-work.md` or their records. The brief says where to look.
- Say in one line that a line nobody reads does nothing, and the way to find out is to test it.

## Testing it

Ask them to open a new chat, because this one remembers writing it. Then try one thing it must answer and one thing it must refuse. If the assistant gets one wrong, the fix is a line in the brief, not a sterner message in the chat.
